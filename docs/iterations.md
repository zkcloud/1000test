# 开发与验收记录

范围：已确认设计的首期平台，TypeScript + Vue 3、FastAPI、SQLite。每轮开发完成后必须通过调测与验收再推进。不会把本地通过等同于已完成生产上线。

1. 服务端完整流程与权限：访客隔离、考试答案防泄露、服务端计时评分、练习首次作答统计、材料原版、保存版本竞争。验收依据为 API 集成测试。
2. 前端页面与交互：试卷大厅、真实题库作答、材料阅读、自动下一题、保存恢复、成绩与回顾。验收依据为类型检查、构建和端到端浏览器测试。
3. 商用部署准备：依赖更新/漏洞审计、安全响应头、生产资源托管、部署/备份/恢复说明、失败与并发场景。记录真实验证结果及剩余上线条件。
