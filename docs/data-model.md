# SQLite 题库设计

数据库位于 `data/questions.sqlite3`，使用 SQLite 外键约束、事务和 schema 版本。原 PDF 保留不变。

| 表 | 用途与主要字段 |
| --- | --- |
| sources | 来源文件名、SHA-256、页数、导入时间；相同文件不重复导入 |
| source_pages | PDF 物理页码、书内页码、原始文本，供追溯 |
| exams | 试卷编号、标题、作答时长（75 分钟） |
| passages | 共用阅读材料：Part、题号范围、引导语、正文、来源页码 |
| passage_assets | 材料原版截图（JPEG BLOB）、页码、裁剪坐标、顺序；保存图片和版式 |
| questions | 题号、Part、单选题型、题干、共用材料外键、来源页码、可用状态 |
| options | 题目外键、A/B/C/D 标签、正文，每题标签唯一 |
| answers | 正确选项、答案来源页码；外键指向真实选项，和题干分表，避免提前泄露答案 |
| explanations | 原书解析原文、来源页码；不自动生成或推断 |
| import_issues | 结构异常或待核对信息，关联来源、试卷、题号 |

关系：来源 → 试卷 → 题目 → 选项；阅读材料 → 多道题目；题目 → 答案/解析。Part 5 为独立填空题，Part 6/7 关联共用材料。Part 6 没有独立题干时，使用“选择第 N 空的最佳答案”作为显示提示，原文留在材料里。

页码均为 **PDF 物理页码，从 1 开始**。原书页脚单独保存，不混入题干。清洗仅处理空白、分页和跨行断开的连续填空横线，不猜测或改写原书措辞。材料保存纯文本和原版截图，图片内文字不冒充已识别文本。

导入须满足每套试卷题号 101–200 完整、每题恰好 A–D 四个非空选项、每题有答案、Part 6/7 有共用材料。结构异常保留并标记，禁止作为 ready 题目使用。解析保留原书解释片段，不能等同于逐字人工校对。

实际导入数量、异常和检查结果见 `data/import-report.json`。运行 `uv run python -m backend.scripts.import_questions` 可重现导入；相同 SHA-256 的来源会跳过，不覆盖已有题库。

未来做题记录应新增独立的练习会话和作答表，引用 question_id，不修改题库或答案。
